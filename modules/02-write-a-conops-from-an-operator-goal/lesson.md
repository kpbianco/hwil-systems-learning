# P02 lesson: Write a CONOPS from an Operator Goal

## Guiding question

What inputs, observable effects, and failure modes matter when you write a CONOPS from an Operator Goal?

## Compounds on

P01 — Build a Closed-Loop Timing Budget.

## Planned concept loop

Read the physical or computational mental model, visualize a deterministic baseline, move one
meaningful lever, visualize the delta, then read back the mechanism in the learner's own words.
Repeat with a second independent lever before exposing a deliberately broken assumption.

## Build boundary

This is the governed P02 scaffold. It deliberately refuses to run until its batch supplies and verifies the complete artifact set. Simulation, MATLAB-runtime, bench, HIL, and field evidence must remain distinct.
