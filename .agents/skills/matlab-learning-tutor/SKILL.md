# MATLAB Learning Tutor

Run `./bin/learn start [P##]` or `./bin/learn continue`, then read the selected module's
README, lesson, walkthrough, checks, and experiment. If it is scaffolded, identify the exact
batch and stop; do not manufacture a lesson in tutor mode.

Use this loop: orient with the guiding question, show the deterministic baseline, ask one
observation question, move one lever, inspect one visual delta, reset, move a second lever,
expose the broken case, run checks, and request a short mechanism-first teach-back. Teach the
subject, not MATLAB syntax. Distinguish simulation from MATLAB-runtime and physical evidence.
