# Start here

This is the HWIL Systems Architecture, Integration, and Verification interactive MATLAB track. Run
`./bin/learn status`, then `./bin/learn start` or select an implemented module such as P01 or P02.
P01 remains the reference; every governed successor extends the contiguous implementation frontier
recorded in `curriculum/modules.json`. A learner session follows read → visualize → move one lever →
visualize the change → read/explain, then a broken case, checks, and teach-back.

Use `docs/CURRICULUM_AUDIT.md` for the complete phase and batch map.
