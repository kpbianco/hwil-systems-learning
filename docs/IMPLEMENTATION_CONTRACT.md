# Module implementation contract

One P## batch implements one module. Preserve its title, question, phase, prerequisites, and folder.
The required loop is read → visualize baseline → move one lever → visualize the delta → read and
explain. Repeat with a second lever, then break one assumption, check invariants, and teach back.
An implementation must separate `model.m`, `experiment.m`, `interactive.m`, tutor Markdown, and
`run_checks.m`; it must also retain honest evidence and keep implemented modules a contiguous prefix.
