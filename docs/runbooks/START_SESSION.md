# Start a learning session

1. Run `./bin/learn status`.
2. Run `./bin/learn start` or select an implemented module explicitly.
3. In MATLAB, run `launch_lesson("P01")` for the current implemented reference module.
4. Follow the module walkthrough one visual transition at a time.
5. Run `run_module_checks("P01")`, give a teach-back, then record completion through the CLI.
