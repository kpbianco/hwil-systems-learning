## Changed invariants

- P04 lifecycle changes from `scaffolded`/`none` to `implemented`/`simulated` only after its staged gates pass.
- Implemented modules form the contiguous P01–P04 prefix at this batch point; shared tests derive the frontier
  so later batches may advance it.
- P04 adds a fixed ten-function logical chain with explicit function inputs, outputs, failure modes, and
  activation evidence while making no hardware/software allocation.
- A complete architecture preserves the original request, rejects out-of-authority input before motion,
  and separates local monitoring from the end-to-end request-goal result.
- Cancellation wins a tie with completion or the deadline; confirmation exactly at the deadline passes when
  cancellation is absent; timeout follows otherwise; no position or correction changes after any terminal
  report. Post-terminal padding is fixed-size

- Response fraction controls the geometric correction recurrence. Confirmation depth controls only evidence
  lag for the monotonic instructional trace.
- The deliberately broken mode represents one collapsed architectural shortcut: validation is omitted and
  original request identity is overwritten by a clipped local target, making false success observable.

## Independent implementation audit repairs

- Finding: `Step` on a spinner does not prevent a learner from typing a fractional or off-grid value, so the
  initial confirmation and deadline controls could pass `2.5` or `999` into strict model validation and make
  the callback throw.
- Repair: confirmation now enables integer rounding and deadline selection is a non-editable dropdown over
  every allowed 20-millisecond value from 100 through 2000. Durable source tests bind both guards; actual UI
  entry remains unperformed without MATLAB.
- Finding: `safeHoldCommanded` implied that cancellation/timeout had produced a physical hold, while the model
  only terminated and padded an instructional trace.
- Repair: the output is now `safeHoldRequired`; cancellation/deadline functions explicitly emit the requirement,
  post-terminal padding is named trace termination, and lesson, UI, checks, tests, and evidence disclaim a
  commanded or verified hold.
- Scope: the audit and repairs changed only P04-owned module/test/evidence paths. The manifest identity,
  function-chain equation, public model arguments, allowed shared files, and forbidden-path state were preserved.

## Independent system-risk review repair

- Finding: P04 inherits P02's cancellation safety precedence and the model checks cancellation before both
  completion and deadline handling, but the retained tests covered only the cancellation-versus-completion
  tie. A refactor could therefore reverse the cancellation-versus-deadline tie to `deadline-missed` without
  failing an executed behavioral gate.
- Repair: the independent Python oracle now executes a cancellation exactly at the 100-millisecond deadline
  and requires the `cancelled` result, cancellation observation, no success, and a safe-hold requirement. The
  retained MATLAB checks assert the same boundary, and lesson/check text states both precedence ties.
- Scope: the repair changes only P04-owned module, test, and evidence files. The model behavior, public model
  arguments and outputs, manifest lifecycle, shared files, and forbidden-path state are unchanged.
