## Independent audits and repairs

Two bounded read-only audits were performed with the primary agent retaining all integration edits: one for
MATLAB/formula correctness and one for acceptance, scope, durable tests, and evidence. They found no critical
or high-severity issue. Their medium findings and repairs were:

- cancellation and timeout originally left precomputed receiver-clause truth observable despite claiming that
  no receiver evaluation occurred; public match flags, clause results, and margins are now masked to false or
  `NaN` whenever transfer is blocked, receiver clause formulas now execute only after an attempted transfer,
  and event-isolation checks cover those outputs in both the MATLAB checks and Python oracle;
- the unit-mismatch case originally exposed a radian numerical margin with a degree label; factual
  `rangeMarginDeg` is now defined only after a degree-unit match, while a separately named
  `receiverAssumedRangeMarginDeg` makes the deliberately broken receiver assumption explicit;
- the logical-record inventory could be read as treating payload length and unit text as unnamed numeric
  payload words; the model and lesson now distinguish two envelope metadata items from six numeric payload
  fields and state exactly what the checksum covers;
- shared learner-facing docs and manifest initially retained the P07 frontier by design; they were promoted to
  P08 only after the repaired isolated candidate gates passed;
- focused static tests originally asserted some labels more strongly than their implementing formulas and
  scanned only `model.m` for opaque operations; they now bind each clause, guard, normalization rule, and tie
  precedence to source formulas and scan every P08 MATLAB file.
- final model re-audit found that `receiverDecisionCorrect` was vacuously true when cancellation or timeout
  made both acceptance and conformance false; it is now gated on an attempted transfer and asserted false for
  every blocked-transfer case.

## Independent system-risk review repair

- Finding: the lesson asks which seven contract clauses the deliberately broken value-only validator ignores,
  but the available executed Python gate demonstrated scenario behavior only for unit mismatch. Version,
  payload-length, malformed-quality, and checksum cases existed only in the unexecuted MATLAB check source;
  identity and sequence were absent from that value-only matrix as well. The retained evidence therefore did
  not behaviorally support the full seven-clause claim.
- Repair: the independent Python oracle now pairs complete and value-only decisions for identity, version,
  payload length, unit, sequence, quality encoding, and checksum failures. Each pair must preserve arrival,
  payload, clause truth, conformance, and failure diagnosis while complete validation rejects and value-only
  validation falsely accepts and releases the plausible number. The MATLAB regression matrix now includes the
  previously missing identity and sequence cases and covers the same seven clauses.
- Scope: the repair changes only P08-owned `run_checks.m`, `tests/test_p08_module.py`, and this retained evidence.
  The deterministic model, public model arguments and outputs, manifest lifecycle, prerequisite interfaces,
  shared learner files, and operator-managed active-batch selector remain unchanged.
