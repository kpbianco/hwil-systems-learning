# Architecture

`curriculum/modules.json` owns the canonical 24-module identity and order. Each module owns a
deterministic model, presentation experiment, interactive controls, tutor narrative, walkthrough,
and checks. The learner CLI owns only selection and ignored `.learning/` progress. Portfolio
Control owns intent, batch sequencing, scope, and evidence requirements; this repository owns the
HWIL Systems Architecture, Integration, and Verification content and its validation.
